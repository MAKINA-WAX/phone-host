# 换电脑使用说明（便携清单）

> 一句话：**新电脑什么都不用装，手机插上数据线就能用。** 但要把两个文件夹一起带走。

## 1. 要带走什么

把这一整个目录复制到新电脑（U 盘 / 网盘 / 局域网都行）：

```
tablet\
├── pc-mode\                  ← 所有脚本、启动器、手机侧脚本
└── scrcpy-win64-v5.0.1\      ← scrcpy + adb（绿色版，不用安装）
```

⚠️ **两个文件夹必须保持同级**（`pc-mode` 里的脚本用 `..\scrcpy-win64-v5.0.1\` 找 adb 和 scrcpy）。
复制到 D 盘、桌面、随便哪里都行，路径别改相对关系即可。

## 2. 新电脑需要装什么

**不需要装任何东西。**

- `adb.exe`、`scrcpy.exe` 都在 `scrcpy-win64-v5.0.1` 里，绿色运行
- 不需要 Python / Node / Java / Android Studio
- 只依赖 Windows 自带的 PowerShell

## 3. 第一次连接（每台新电脑一次）

1. 手机用**数据线**插到新电脑（注意：有些线只能充电，不能传数据）
2. 手机会弹「**允许 USB 调试吗？**」→ 勾选 **一律允许** → 允许
3. 双击 `pc-mode\启动.bat`，顶部状态区应显示机型和电量
4. 如果显示"未连接手机"：
   - 手机上 USB 用途改成"传输文件/传输照片"
   - Windows 设备管理器里看有没有带感叹号的 Android 设备 → 装通用 ADB 驱动
   - 换一根线再试

> 每台电脑的 RSA 指纹不同，所以第一台之后换电脑都要再点一次"允许"。

## 4. 分辨率/缩放会自动适配

新电脑的分辨率和 DPI 缩放**不用手动改**：

- `auto-start.ps1` 会读取该电脑显示器的**物理分辨率**（DPI 感知，不会被缩放骗），按它建虚拟屏并铺满
- 密度按 `160 × 宽 / 1163` 反算，所以桌面可用空间恒定
- 镜像模式（`⑥ 手机屏幕镜像` / `switch.bat`）也改成走 `mirror-phone.ps1`，同样自适应

唯一要留意的是：**别按 Alt+F**（scrcpy 自带全屏在高 DPI 下会放大裁切），窗口参数已经铺满了。

## 5. 新电脑上的常用操作

```bat
启动.bat        控制台（推荐入口）
check.bat       环境检测（看差什么）
setup.bat       一键补齐环境（会自己装 APK / XFCE / 加固）
stop-pc.bat     收工，清干净
```

## 6. 已知的坑（脚本里已处理）

| 坑 | 处理 |
|---|---|
| `%TEMP%` 写不了导致 adb 起不来 | 所有 bat/ps1 都把 TEMP 指向 `pc-mode\tmp\` |
| 电源计划/系统缩放 200% | 计算分辨率前先 `SetProcessDpiAwarenessContext` |
| 窗口被浏览器盖住 | `bring-back.bat` |
| 手机清后台后黑屏 | 启动器内置自动恢复（15s 检查 + 黑屏像素检测） |

## 7. 手机上要保鲜的（换电脑不影响）

- USB 调试开着
- 手机侧守护（host-mode / notify-bridge）只在手机里，跟电脑无关
- 新电脑不需要重新配置手机

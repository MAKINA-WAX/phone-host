# 项目文件结构

> 根目录：`项目根目录\`（可整体拷到别的电脑，保持 pc-mode 和 scrcpy 同级即可运行）

```
tablet\
├─ pc-mode\                     ★ 主工作目录（所有脚本、文档、APK）
│  ├─ 启动.bat                  ← 总入口：开控制台（同时带起自动重连守护）
│  ├─ pc-launcher.ps1           控制台 UI（WinForms，DPI 感知，可调界面缩放）
│  ├─ launcher.json             控制台配置：码率/帧率/起始App/界面缩放/上次模式
│  │
│  ├─ 【投屏 · 电脑端】
│  ├─ auto-start.ps1            开画布：按显示器分辨率建虚拟屏 2880×1800 并铺满
│  ├─ mirror-phone.ps1          手机镜像（-Mode full|window，-Mouse sdk|uhid）
│  ├─ mirror-touch.bat          手机镜像 · 全屏 + 真触摸点击
│  ├─ mirror-window.bat         手机镜像 · 可拖动窗口（有标题栏）
│  ├─ desktop-show.ps1/.bat     把手机上已跑的 Linux 桌面接管到电脑显示
│  ├─ start-xfce.ps1            开 Linux 桌面（-Attach 只切回前台 / -Stop 停止）
│  ├─ start-xfce.sh             手机端：起 termux-x11 + XFCE
│  ├─ focus-scrcpy.ps1          把投屏窗口拉到前台
│  ├─ window-toggle.ps1         全屏 ↔ 窗口切换
│  ├─ toggle-window.bat         同上（bat 入口）
│  ├─ 切换全屏（Ctrl+Alt+F）.lnk  全局快捷键（需放桌面/开始菜单才生效）
│  │
│  ├─ 【游戏 · 防烧屏】
│  ├─ game-mode.ps1             亮度压 0（OLED 黑）+ 手柄直通 + 全屏
│  ├─ mirror-game.bat           入口：亮度 0 方案
│  ├─ game-vd.ps1               游戏跑虚拟屏 + 物理屏真熄（防烧屏）
│  ├─ mirror-game-vd.bat        入口：虚拟屏方案
│  │
│  ├─ 【守护 · 自动恢复】
│  ├─ watch-reconnect.ps1       每 4 秒轮询：插拔重连 / 崩溃重试 / 手机请求投屏
│  ├─ watch-reconnect.bat       入口（单实例）
│  ├─ resume.bat                手动关闭投屏后恢复守护
│  ├─ reconnect.log             守护日志（运行时生成）
│  ├─ last-mode.txt             上次使用的模式（重连时按它恢复）
│  ├─ paused.flag               暂停标记（stop-pc / 手动关投屏时生成）
│  │
│  ├─ 【环境 · 体检 · 收工】
│  ├─ doctor.ps1 / check.bat    环境检测（14 项）
│  ├─ provision.ps1 / setup.bat 一键补环境（装 APK、装 XFCE、加固后台）
│  ├─ harden.ps1 / harden.bat   后台加固（appops / doze 白名单 / standby bucket）
│  ├─ 2-start-pc.bat            开画布（auto-start.ps1 的 bat 入口）
│  ├─ 5-xfce.bat                开 Linux 桌面（bat 入口）
│  ├─ switch.bat                三选一：桌面 / App / 镜像
│  ├─ bring-back.bat            窗口被盖住时拉回
│  ├─ stop-pc.bat               收工（关投屏 + 杀手机端 server + 暂停守护）
│  ├─ stop-xfce.bat             只停 Linux 桌面
│  ├─ to-desktop.bat / 2-app-full.bat / open-app.ps1   各种切窗入口
│  ├─ test-pad.ps1 / test-pad.bat  手柄自检（实时显示 XInput 按键）
│  │
│  ├─ 【手机端脚本】phone\
│  │  ├─ launcher.sh            手机端启动器（TUI 菜单，9 项 + p/q 投屏请求）
│  │  ├─ host-mode.sh           模式仲裁守护（插电开桌面/拔电停、温度调度）
│  │  ├─ notify-bridge.sh       通知回传（安卓通知 → Linux 桌面）
│  │  └─ start-host.sh          开机自启入口（部署到 ~/.termux/boot/）
│  │
│  ├─ 【APK】5 个，共 67 MB
│  │  ├─ termux.apk            Termux 主程序（debug 版，可用 run-as）
│  │  ├─ termux-x11.apk        X11 显示端
│  │  ├─ termux-api.apk        电量/温度/通知 API
│  │  ├─ termux-boot.apk       开机自启
│  │  └─ termux-widget.apk     桌面小组件（一键启动器）
│  │
│  ├─ 【文档】
│  │  ├─ README-手机PC模式.md   入门说明
│  │  ├─ 开发文档.md            技术细节 §1–16
│  │  └─ 换电脑使用说明.md        换电脑的移植清单
│  │
│  ├─ 【已弃用】_pc-style-deprecated\   Android 桌面 PC 化那套（Taskbar 等）
│  ├─ 【临时】tmp\               adb.log / 心跳 / pid / vd-id 等运行时文件
│  └─ *.png                    54 张调试截图（可清理）
│
└─ scrcpy-win64-v5.0.1\         投屏工具（scrcpy 5.0.1 + adb + SDL3）
```

## 几条主线

| 你想做的事 | 入口 |
|---|---|
| 日常开电脑看手机 | `启动.bat` → ⑥ 手机镜像 |
| 用 Linux 桌面 | `启动.bat` → ② 开画布 → ③ 开 Linux 桌面 |
| 手机上点一下就投屏 | 手机 Termux 启动器 → `p) 投屏到电脑` |
| 玩游戏（防烧屏） | `mirror-game-vd.bat` |
| 检查环境 | `check.bat` |
| 手工修环境 | `setup.bat`、`harden.bat` |
| 收工 | `stop-pc.bat` |

## 运行时会生成的文件

```
reconnect.log        守护日志
last-mode.txt        上次模式
paused.flag          暂停标记
tmp\watch-reconnect.pid     守护进程号
tmp\watch.heartbeat         守护心跳
tmp\vd-id.txt               当前虚拟屏 displayId
tmp\brightness.bak          游戏模式前的亮度
```

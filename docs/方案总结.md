# 用 Redmi K70 Pro 当"主机"的可行性总结

> 结论：**可行，但定位是"轻办公 + 轻服务"主机，不是 PC 替代品。**
> 手机算力足够（骁龙 8 Gen 2 / 12GB），真正的瓶颈不在性能，而在三件事：ARM 架构无 x86 兼容、HyperOS 后台管理、系统权限限制。

## 三、实测踩到的三个系统限制

1. **不能改分辨率/密度**
   `adb shell wm size 1600x1000` 被拒：
   `SecurityException: requires android.permission.WRITE_SECURE_SETTINGS`
   原因：HyperOS 需要开启「开发者选项 → USB 调试（安全设置）」才给 adb shell 这个权限。

2. **强制转横屏无效**
   `settings put system user_rotation 1` 写进去了但屏幕不转；手机本身锁竖屏（`accelerometer_rotation=0`）。只有 scrcpy 的 `--display-orientation=90` 能真正转动显示，但窗口不会跟着重算尺寸。

3. **scrcpy `--fullscreen` 参数有坑**
   在 1440×900 屏上启用 `--fullscreen` 会导致画面被放大 1.5 倍并四边裁切（DPI 100% 下仍发生，判定为该版本 bug）。
   **可用替代**：`--window-borderless --window-x 0 --window-y 0 --window-width 1440 --window-height 900`，视觉上等价全屏，且画面完整。

**投屏尺寸的数学关系**：手机竖屏 1080×2400（比例 1:2.22）投到 1440×900 横屏，按高度适配后只剩 **405×900 的竖条**，这是比例决定的，不是设置问题。想铺满必须改逻辑分辨率成 16:10。

## 四、四条路线的可行性

| 路线 | 结论 | 关键限制 |
|---|---|---|
| A. 手机当办公/日用主机（PC 只当显示器+键鼠） | ✅ 最现实 | 无桌面模式，单窗口全屏操作；需开安全调试权限才能铺满 |
| B. 手机当 Linux 服务器/开发机（Termux + proot Ubuntu） | ✅ 靠谱 | 无 root，跑不了 Docker；HyperOS 杀后台，需锁后台+关省电 |
| C. 手机跑 PC 游戏（Winlator / Box64 转译） | ⚠️ 勉强 | 转译损耗大，老游戏/独立游戏可，3A 无望 |
| D. 手机当本地 AI 推理主机（llama.cpp 3B~8B） | ✅ 能跑 | 8B Q4 约 3~6 token/s，慢但可用 |

## 五、推荐方案 A 的落地步骤

**前置（一次性）**：开发者选项里打开「USB 调试（安全设置）」并允许弹窗。
不开也行，那就只能接受竖条投屏或横屏留黑边。

```bash
# 1) 把手机逻辑分辨率改成显示器同比例（16:10），密度下调让 UI 更"电脑"
adb shell wm size 1600x1000
adb shell wm density 240

# 2) 启动投屏（无边框满屏 + 键鼠直通 + 保持唤醒 + 手机黑屏省电）
scrcpy --serial <序列号> --window-borderless --window-x 0 --window-y 0 \
       --window-width 1440 --window-height 900 \
       --max-fps 60 --max-size 1600 --video-bit-rate 20M \
       --keyboard=uhid --mouse=uhid --stay-awake --turn-screen-off
```

**回滚（很重要，别忘了）**：
```bash
adb shell wm size reset
adb shell wm density reset
```

**配套建议**
- 手机一直插着充电，配散热背夹（满载 10 分钟必降频）
- 关掉手机的省电优化、把常用应用加入后台白名单
- `Alt+O` 可随时开关手机屏幕；`Alt+F` 切换全屏/窗口

## 六、方案 B 的要点（如果后面想当服务器）

```bash
# 手机侧：Termux 里
pkg install proot-distro && proot-distro install ubuntu
proot-distro login ubuntu          # 进入 Ubuntu
apt install openssh-server nodejs python3
# 起 sshd 后用 USB 端口转发，电脑免网络直连
adb forward tcp:8022 tcp:8022
ssh -p 8022 user@127.0.0.1
```
注意：proot 不是真容器，systemd 跑不了，用 `sshd` 直接起进程即可。

## 七、风险与对策

| 风险 | 说明 | 对策 |
|---|---|---|
| 发热降频 | 8 Gen 2 满载 10 分钟开始掉性能 | 散热背夹 + 通风，长任务分批跑 |
| 后台被杀 | HyperOS 对非白名单进程下手很重 | 关省电、锁后台、必要时前台常驻通知 |
| 无 x86 兼容 | Windows 程序/PC 游戏基本跑不了 | 别把这条路当主方案 |
| 无 root | 不能 Docker、不能改内核、不能全局代理 | 用 Termux + proot 替代；或考虑解 BL 锁（有风险） |
| 安全设置权限 | 开了等于把改系统设置的能力交给电脑 | 用完关掉该开关 |
| 数据安全 | 手机里 178GB 已用（含微信/银行/相册） | 当主机时别在公共环境开着安全调试 |

## 八、一句话总结

这台 K70 Pro 的算力完全够当"轻量主机"：**投屏当办公桌面、Termux 当 Linux 服务器、llama.cpp 当本地 AI 节点**这三件事都能做且体验不差；唯一要接受的是它替代不了 PC——没有 x86 兼容、没有真多窗口、长时间高负载会降频。真正的门槛不是硬件，而是那两个系统开关（安全调试权限、后台白名单）。

## 附：想要 DeX 那种"PC 模式"？（后续补充，见 `pc-mode/`）

### 结论
HyperOS 3（Android 16）**没有内置桌面模式，也没有 DeX 那套东西**：系统里查不到任何 desktop/自由窗口组件，只有 `com.xiaomi.mirror`（妙享投屏）。所谓"PC 模式"要自己拼。

### 本次补测的硬事实
| 探测 | 结果 |
|---|---|
| Type-C 视频输出 | `/sys/class/typec` 为空，无 DP alt-mode 迹象 → **一根线直连显示器不可行** |
| `settings put global enable_freeform_support 1` | 仍被拒：`SecurityException: WRITE_SECURE_SETTINGS` |
| `am task resize` / `am start --windowingMode 5` | 无效，任务保持 `mode=fullscreen` |
| `adb install` | ✅ 打开「USB 安装」后已成功装上 Taskbar 6.2.2 |
| `scrcpy --new-display=1600x1000/220` | ✅ **可用**，手机上多出独立虚拟屏，本机屏幕不受影响 |
| 虚拟屏上的应用窗口模式 | ✅ **`mode=freeform`**：Chrome、设置、计算器可同时各占一个窗口，底部还有 Taskbar 任务栏 |

### 三条路线
1. **自由窗口 + Taskbar 桌面壳 + scrcpy 满屏**（推荐，最像 DeX：多窗口/任务栏/开始菜单/Alt+Tab）
2. **Termux + XFCE（termux-x11）**：真 Linux 桌面，任意窗口，但要接受 Linux 版软件
3. Winlator 跑 Windows 程序：只能玩老游戏和小工具，不算 PC 模式

### 落地
看 `tablet/pc-mode/README-手机PC模式.md`。现状：
- `2-start-pc.bat` **现在就能跑**：开一块 `1600x1000` 的虚拟屏，满屏投到显示器，不改手机任何设置，16:10 铺满不再有 405×900 的竖条
- **多窗口已经通了**：虚拟屏上的应用默认就是 freeform 窗口，Taskbar 在底部做任务栏/开始菜单/托盘，鼠标可拖窗口、键盘可直接打字
- 那个「USB 调试（安全设置）」开关**不是必需的**，只有想让手机本机屏幕也能开小窗时才需要（`1-enable-freeform.bat` + 重启）

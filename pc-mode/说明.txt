手机主机 · 安装包   v1.2
====================

【安装顺序】先装电脑端，再从控制台装手机端
------------------------------------------------
第 1 步：双击「安装.bat」装电脑端
   - 只勾「电脑端：脚本 + scrcpy」+ 桌面快捷方式
   - 装完电脑端就完整可用了（脚本 + 投屏工具 + 文档）

第 2 步：打开桌面的「手机主机」控制台
   - 点 ⑦ 装手机端
   - 手机插数据线、开 USB 调试、弹窗点「允许」
   - 界面里会显示设备信息（型号 / Android 版本 / uhid / 真触摸权限）
   - 勾选要装的内容（默认全选前 4 项），点「开始安装」
   - 装完自动建画布 + 开 LXQt 桌面

这样每换一台手机，只需在控制台点 ⑦，不用重新装电脑端。

【第 2 步会自动做的事】
① 装 5 个 APK：Termux / X11 / API / Boot / Widget
② 装 Termux 桌面环境：LXQt + openbox + ibus 拼音 + PulseAudio 音频（约 1.6 GB）
   - 自动测速选最快的镜像源（清华 / 中科大 / 阿里云）
   - 自动绕过 xdg-utils 的 cpan 报错
③ 部署手机端脚本：start-lxqt.sh / host-mode.sh / launcher.sh 等 + 开机自启
④ 终端优化：关掉 Termux:X11 底部额外按键条、默认输入法设为拼音
⑤ 自适应：按你电脑屏幕比例算出虚拟屏尺寸

【v1.2 更新内容】
- 新增：控制台 ⑦「装手机端」——手机端全自动安装与适配（就是本流程）
- 新增：兼容性检测（型号 / Android 版本 / uhid / 真触摸 / 存储 / 推荐分辨率）
- 新增：镜像源自动测速切换
- 修复：Termux:X11 底部额外按键条挡住桌面
- 修复：同时出现两个桌面的问题
- 新增：界面缩放工具（DPI / 面板 / 字体 / Firefox 一起调）
- 新增：中文输入法（ibus + libpinyin，Ctrl+Space 切中英）
- 新增：声音输出（PulseAudio → Android，视频有声音了）
- 默认桌面：LXQt（XFCE 保留）

【装完怎么用】
- 控制台：桌面双击「手机主机」
- 开画布 + 开桌面：控制台点 ② → ③
- 调缩放：双击「桌面缩放.bat」（默认 1.25 倍）
- 换手机：控制台点 ⑦，重复第 2 步即可

【手机端还需要手工开的（一次性）】
- 开发者选项 → USB 调试（安全设置）    ← 不开鼠标是「指针」不是「手指」
- 省电策略 → 无限制；自启动 → 开；最近任务 → 锁住 Termux 和 Termux:X11

【卸载】
双击「卸载.bat」，可勾选：
  ☑ 删除程序文件（整个安装目录）
  ☑ 删除桌面快捷方式
  ☑ 删除计划任务
  ☐ 卸载手机端 5 个 APK（勾了会把 Termux 和里面的 Linux 一起删掉！）

【注意】
- 本安装包不含截图和历史日志（体积原因）
- 手机端 APK 必须用数据线装（MIUI 不允许电脑静默安装）
- 中文输入：Ctrl+Space 切换中英文，数字键选候选字

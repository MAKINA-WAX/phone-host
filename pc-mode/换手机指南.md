# 换一台手机能不能用？

结论：**大部分能，但有几条硬门槛。** 插上新手机跑一次 `check-device.ps1` 就知道。

```powershell
cd pc-mode
.\check-device.ps1
```

## 硬性要求（不满足就跑不了）

| 要求 | 为什么 | 不满足会怎样 |
|---|---|---|
| **Android 12+（SDK 31）** | scrcpy 的 `--new-display` 虚拟屏需要 | 完全跑不了，只能做普通镜像 |
| **arm64 架构** | Termux 官方只有 arm64 包 | 装不上或极慢 |
| **能开 USB 调试** | 电脑靠 adb 驱动一切 | 无法操作 |
| **可装 Termux** | 整个 Linux 都跑在里面 | 没有 Linux |

## 强烈建议（影响体验）

| 要求 | 说明 |
|---|---|
| **Android 13+（SDK 33）** | uhid 键鼠直通，键盘/鼠标/手柄才是「真设备」 |
| **USB 调试（安全设置）** | 小米/红米需要单独开，否则鼠标点击是「指针」不是「手指」 |
| **Termux 不被杀** | 需要手动设「省电无限制 + 自启动 + 最近任务锁定」 |
| **剩余空间 ≥ 5 GB** | 桌面 + 浏览器 + 开发工具大约占 3~4 GB |
| **能装 5 个 Termux APK** | Termux / X11 / API / Boot / Widget |

## 各家手机注意点

| 厂商/系统 | 注意 |
|---|---|
| **小米 / 红米（MIUI、HyperOS）** | 必须开「USB 调试（安全设置）」；省电策略很激进，Termux 要手动设"无限制"；`pm disable-user` 被禁 |
| **OPPO / vivo / realme** | 后台杀得更狠，需要「自启动 + 电池优化白名单」；部分机型限制 USB 安装 APK |
| **华为 / 荣耀（HarmonyOS）** | 老机型可能没有 uhid；`pm install` 需要点允许 |
| **三星** | 通常最省事，开发者选项里「允许通过 USB 安装」要打开 |
| **原生 Android / Pixel** | 最顺，什么都不用额外设 |
| **安卓模拟器 / 平板** | 一般也能用，但虚拟屏在模拟器里可能没有 uhid |

## 项目里跟设备绑定的是什么

只有两处，而且都是「参数」不是「写死」：

| 位置 | 内容 | 换手机是否需要改 |
|---|---|---|
| `auto-start.ps1` | 密度公式 `density = 160 × 宽 / 1163` | 建议改成按新手机算（脚本会自动算，也可 `-ForceDpi` 覆盖） |
| `game-vd.ps1` | 游戏窗口 2880×1296 | 按你的电脑屏幕，跟手机无关 |
| `check-device.ps1` | 运行时读 `wm size` / `wm density` | 自动适配 |

**没有任何写死的机型名、序列号、分辨率**，所以换手机不用改代码。

## 换手机的完整流程

```powershell
# 1. 新手机：开发者选项 → USB 调试（+ 安全设置）→ 连电脑 → 允许
# 2. 检测
cd pc-mode
.\check-device.ps1

# 3. 装手机端（5 个 APK）
#    双击桌面「手机主机」→ 控制台 / 或用 安装.bat 勾选「手机端」

# 4. 手机 Termux 里装环境（第一次必须）
#    见 安装与使用.md 第一节

# 5. 开画布 + 开桌面
.\auto-start.ps1          # 会自动按你的电脑屏幕算分辨率
.\LXQt桌面.bat
```

## 检测脚本会输出什么

```
设备信息      品牌型号 / Android 版本 / SDK / 架构 / MIUI 版本
系统要求      Android 12+ / 13+ / arm64
关键能力      uhid / INJECT_EVENTS / WRITE_SECURE_SETTINGS / 截图
屏幕         物理分辨率 / 密度 / 逻辑 dp
推荐虚拟屏    按你电脑屏幕比例算好的尺寸 + 命令
Termux 套件   5 个包是否已装
存储          /data 剩余空间
结论          OK / 注意 / 不满足 三项计数 + 一句话结论
```

## 已知不通用的情况

1. **Android 11 及以下** —— 没有虚拟屏，本方案的核心用不了
2. **x86 手机/平板** —— Termux 包不兼容
3. **深度定制且锁 bootloader 的系统** —— 有些功能（如 secure settings）拿不到权限
4. **折叠屏/超宽屏** —— 能跑，但虚拟屏比例要手动调 `-ForceW/-ForceH`
